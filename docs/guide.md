# shotmark 使用手册

一款轻量网页截图标注工具：一行启动、零 UI 库依赖、本地栅格化。本手册覆盖全部功能、快捷键与常见场景。
完整 API 见 [README](../README.md)，实现原理见 [architecture.md](./architecture.md)。

## 一、安装与最简接入

```bash
pnpm add shotmark   # react / react-dom 为 peer 依赖(>=17),需自行安装
```

```ts
import Shotmark from 'shotmark';

// 自由框选截图
Shotmark.start({ onShot: (res) => console.log(res.image) });

// 或指定区域直接进入标注
Shotmark.start({
  region: document.querySelector('#card'),
  autoAnnotate: true,
  onShot: (res) => upload(res.image),
});
```

## 二、标注工具一览

| 工具           | 说明                                | 可调配置         |
| -------------- | ----------------------------------- | ---------------- |
| 矩形 rectangle | 矩形框                              | 颜色、线宽       |
| 椭圆 ellipse   | 椭圆框                              | 颜色、线宽       |
| 箭头 arrow     | 指向箭头                            | 颜色、线宽       |
| 直线 line      | 直线段                              | 颜色、线宽       |
| 尺寸 measure   | 标注两点像素距离(自动吸附水平/垂直) | 颜色             |
| 画笔 brush     | 自由手绘                            | 颜色、线宽       |
| 高亮 highlight | 半透明色块强调,不遮挡底图           | 颜色、透明度     |
| 马赛克 mosaic  | 像素化遮挡敏感区域                  | 块大小、柔化强度 |
| 文字 text      | 文本标注                            | 颜色、字号       |
| 序号 number    | 自动步骤编号(默认字号 12)           | 颜色、字号       |

## 三、快捷键

| 按键                   | 作用                                                 |
| ---------------------- | ---------------------------------------------------- |
| `1`~`9`                | 按工具栏顺序切换前 9 个工具(主键盘数字区/小键盘均可) |
| `0`                    | 切换到第 10 个工具                                   |
| `Esc`                  | 关闭截图                                             |
| `Delete` / `Backspace` | 删除选中图形                                         |
| `Ctrl/Cmd + Z`         | 撤销                                                 |
| `Ctrl/Cmd + Shift + Z` | 重做                                                 |
| `Ctrl/Cmd + C`         | 复制截图到剪贴板                                     |
| `Enter`                | step2 进入标注态；step3 确认导出                     |

## 四、交互流程

1. 调用 `start()` 后进入全屏遮罩。
2. 未传 `region` 时：拖拽框选区域(拖拽过程中即显示裁剪调整点)。
3. 选区确定后出现工具栏；点击工具或按数字键进入绘制。
4. 绘制/选中图形时实时显示调整点，可拖拽端点改尺寸、拖本体平移。
5. 点「勾」导出(触发 `onShot`)，或复制/下载/取消。

## 五、配置记忆

- 每个工具"最后一次改动的颜色/尺寸"会记住，切换工具再切回仍保留。
- 跨会话持久化到 localStorage，刷新/下次截图仍生效。
- 优先级：**用户记忆 > `start` 选项默认(如 `defaultColor`) > 内置默认**。
- 没用过的工具首次使用取 `start` 选项或内置默认。

## 六、主题与国际化

- `theme: 'light' | 'dark'`：工具栏/面板/消息/图形调节点随主题切换。
- `locale: 'zh-CN' | 'en-US'`：内置消息文案语言。
- `localeText`：覆盖内置消息与配置面板文案。

## 七、为什么选 shotmark

- **开箱即用的"截图 + 标注"闭环**：纯截图库(如 html2canvas)只负责把 DOM 转成图，标注、工具栏、
  撤销重做、复制下载都要自己做；shotmark 一行启动即拥有完整标注体验。
- **零 UI 库依赖**：不绑定任何组件库，包体小、可嵌入任意技术栈页面。
- **隐私友好**：截图与导出全在浏览器本地完成，不上传服务器。
- **可扩展**：图形插件化，新增标注类型改动面极小。
- **细节到位**：per-tool 记忆、主题、i18n、尺寸吸附、马赛克实时预览、层级不错乱。

## 八、常见问题

- **数字键不切换工具？** 需先框选出区域(step≥2)才响应；焦点需在组件所在文档上下文。
- **Storybook 中数字键失效？** 属 Storybook manager 抢焦点的环境问题，真实业务页面不受影响。
- **导出图为空/异常？** 检查选区是否有效、跨域图片是否设置了 `crossorigin`。
